# Security Policy

## Supported Versions

Only the latest release of Course Index (`course-index` on [PyPI](https://pypi.org/project/course-index/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/academic-templates/course-index/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the Course Index version (`course-index --version` prints it);
- the steps to reproduce the issue, and the `.idx` file (or the lines) involved if relevant;
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
